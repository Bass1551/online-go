# 🏯 เกมหมากล้อมออนไลน์ (Online Go / Baduk)

เว็บเกมหมากล้อมสำหรับเล่นออนไลน์กับเพื่อนหรือแฟนแบบเรียลไทม์ พร้อมระบบห้อง ลิงก์ชวนเล่น กติกาหมากล้อมสากลครบถ้วน และเสียงเอฟเฟกต์สมจริง

---

## 🌟 ฟีเจอร์เด่น (Key Features)

1. **ระบบห้อง & ลิงก์ชวนเล่น (Invite System)**
   - สร้างห้องแล้วกดปุ่ม **"💌 ชวนเพื่อน/แฟน"** เพื่อคัดลอกลิงก์ส่งให้เพื่อนหรือแฟนเปิดบนมือถือหรือคอมพิวเตอร์เพื่อเข้าเล่นได้ทันที
   - กำหนดขนาดกระดานได้ 3 รูปแบบ:
     - **9 × 9**: กระดานเร็ว เล่นจบไว (10-15 นาที) เหมาะสำหรับเล่นเพลินๆ กับแฟน
     - **13 × 13**: กระดานขนาดกลาง
     - **19 × 19**: กระดานมาตรฐานการแข่งขันสากล
   - เลือกจับเวลาได้: ไม่จำกัดเวลา (ชิลๆ), 5 นาที, 10 นาที หรือ 15 นาที

2. **กติกาหมากล้อมที่ถูกต้องตามหลักสากล (Go Rules Engine)**
   - คำนวณลมหายใจ (Liberties) และการกินหมาก (Captures) อัตโนมัติ
   - กฎห้ามฆ่าตัวตาย (Suicide prevention)
   - กฎโคะ (Ko Rule: ห้ามกินกลับทันทีในรูปเดิม)
   - การผ่านตาเดิน (Pass) หากผ่านทั้งสองฝ่ายจะจบเกมและคำนวณพื้นที่
   - คอมิ (Komi): หมากขาวได้แต้มชดเชย +5.5 (กระดาน 9x9) หรือ +6.5 (กระดาน 13x13, 19x19)
   - ระบบขอย้อนหมาก (Undo) และยอมแพ้ (Resign)

3. **ประสบการณ์การเล่น & บรรยากาศ (Polished UI/UX)**
   - กระดานไม้สไตล์ญี่ปุ่น (Kaya Wood) พร้อมเงาและแสงตกกระทบ 3D ของเม็ดหมาก
   - เสียงเอฟเฟกต์สมจริงสังเคราะห์ผ่าน Web Audio API (เสียงวางหมากไม้ เสียงกินหมาก เสียงจบเกม)
   - แชทในเกม พร้อมแถบส่ง **Quick Emojis** (❤️, 🥰, 👏, 🤔, 🥺, 🎉, ☕) ที่จะลอยขึ้นมาบนหน้าจอแบบน่ารักๆ
   - รองรับทุกขนาดหน้าจอ (Responsive Mobile & Desktop)

## 🚀 วิธีเข้าเล่น

### 1. กรณีอยู่คนละที่ / คนละ Wi-Fi (เช่น เพื่อนหรือแฟนอยู่บ้านตัวเอง หรือเล่นผ่าน 4G/5G)
คุณสามารถดับเบิ้ลคลิกไฟล์:
👉 **`start_online_global.bat`**

ระบบจะเปิดเซิร์ฟเวอร์พร้อมสร้างลิงก์อินเทอร์เน็ตสากล (Cloudflare Tunnel) ให้ทันที:
- ตัวอย่างลิงก์: `https://xxxx.trycloudflare.com`
- ส่งลิงก์นี้ให้เพื่อนหรือแฟนเปิดบนมือถือ (iOS / Android) หรือคอมพิวเตอร์ จากที่ไหนก็ได้ในโลก เข้าเล่นได้ทันที 100% ฟรี ไม่ต้องสมัครสมาชิก!

### 2. กรณีเล่นในบ้านเดียวกัน (Wi-Fi เดียวกัน)
- เล่นบนเครื่องคุณ: `http://localhost:3000`
- ให้คนในบ้านเปิด: `http://192.168.1.33:3000`

---

## 🛠️ วิธีการเปิดเกม
- **เล่นข้ามเน็ต (คนละที่)**: ดับเบิ้ลคลิก `start_online_global.bat`
- **เล่นในบ้าน / เครื่องตัวเอง**: ดับเบิ้ลคลิก `start_game.bat`
